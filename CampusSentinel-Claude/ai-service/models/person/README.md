# Person detector weights (pretrained — NOT trained by us)

`yolo26n.pt` is the Ultralytics YOLO26 nano detection model, pretrained on COCO (class 0 = person).
It is downloaded automatically from the official Ultralytics assets release the first time
`training/restricted_zone/demo_video.py` runs (~5.3 MB). Licence: AGPL-3.0 (Ultralytics).
It is not included in code ZIPs.
